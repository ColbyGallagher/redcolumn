Bulk apply scale

Sheets in a set are drawn at different scales. Box the scale note once and redcolumn reads it from every sheet.

How bulk scale works

  • One box, every sheet scaled from its own title block
  • Choose all pages, the current page, or a range like 1-5, 8
  • Pages with no scale found are left as they were
  • Metric and imperial

Page labels from the title block

Turn page 1, page 2 into A-101, A-102. Box the sheet number once and every page is labelled from its own title block.

How page labels work

  • Sheet numbers and titles read from each sheet
  • Written into the PDF, so other PDF apps show them too
  • Used to link sheets and match revisions
  • Fix any single label by hand in the Thumbnails panel

Symbol search and count

Box one light fitting, socket or tree and redcolumn finds every other copy, on this page or the whole set.

How symbol search works

  • Count them, or cloud or box every match in one click
  • Include rotated copies and different sizes
  • Works on scanned sheets by matching the image
  • Step through the matches to check each one

Plan stitching

Roads, pipelines and big buildings are split across sheets. redcolumn finds the match lines and joins the sheets into one continuous plan.

How stitching works

  • Match lines found for you
  • View, mark up and measure across sheet edges
  • Stitch to a new page when you need a single sheet
  • Register the whole stitched set to the map

Assemblies for estimating

Measure a wall once and its assembly works out the studs, track, board and insulation.

How assemblies work

  • Quantity formulas with variables like wall height and stud spacing
  • Waste allowances, rounded up and priced
  • Start from built-in examples: partitions, slab, tile, paint, doors
  • Save your own and share them

Area cutouts

Take out the stair void, lift shaft or courtyard. The net area updates as soon as the hole is closed.

How cutouts work

  • Draw the area, then add as many cutouts as you need
  • Net area and perimeter update straight away
  • Works for volumes too
  • Remove cutouts again with one click

An AI assistant that works on your drawing

The desktop app can let GitHub Copilot, Claude, Codex or Cursor read the open drawing and help. It runs on your computer.

How to switch it on

  • It can see a page, or part of one, and read its text
  • List, place and change markups, and run menu commands
  • Set match lines and stitch sheets end to end
  • Propose a takeoff with its reasoning. You approve each line before it counts

Things you can ask

  • “Stitch these three road sheets together.”
  • “Propose a takeoff for the partition walls I measured.”
  • “List every cloud on page 4 and what it says.”

Draw and annotate like CAD

CAD-style drawing tools

Offset, trim, extend, fillet, chamfer, mirror and arrays, on top of any PDF. Draw and edit geometry the way you would in CAD.

See the editing tools

  • Offset, trim, extend, fillet and chamfer
  • Mirror, rotate, scale and stretch
  • Rectangular, polar and path arrays
  • Custom line styles

Bullet and numbered lists

Real lists in text markups. Type a dash or a number to start one.

  • Tab and Shift+Tab to nest items
  • Numbers renumber themselves
  • A list bar for bullets, numbers, letters and checkboxes
  • Stays plain text, so nothing is lost in other PDF apps

Tables

Draw a table, choose its size and type in the cells.

  • Click a cell to select it, double-click to type
  • Drag lines to resize, drag across cells to merge them
  • Insert or delete rows and columns from the right-click menu
  • Format cells like any other markup

Flow diagrams

Flowchart shapes with connectors that stay attached when you move them.

  • Add the next step to the right, above or below in one click
  • Change a shape to a decision and its connectors stay
  • Branch the flow in any direction
  • Elbow or straight connectors

Geospatial

Model to geospatial PDF

Lay a CAD or survey model over a sheet, line it up with the drawing and register it to real-world coordinates.

  • IFC 4.3, LandXML, DXF and GeoJSON models
  • Line up by dragging, or by two matching points
  • Register one sheet or a whole stitched set
  • Other mapping apps then show latitude and longitude

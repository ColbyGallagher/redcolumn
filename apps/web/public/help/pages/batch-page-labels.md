# Batch Page Labels (AutoMark)

Reads each file's sheet numbers from its title blocks and **writes them into the PDF** as page labels. Other PDF programs then show *A-101* instead of *page 1* too.

1. Choose {{Batch > Page Labels (AutoMark)…}}.

   ![The Batch Page Labels window](img/batch-page-labels.png)
2. Tick the files.
3. Click **Run on *n* files**.

Sheet numbers redcolumn already knows (including ones you corrected yourself) are used as they are. To correct a label first, see [Page labels](#page-labels).

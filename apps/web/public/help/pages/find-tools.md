# Find any tool or command

Can't remember which menu something is in? Search for it.

1. Press [[Ctrl+Shift+K]] (or click {{Help > Find Tools + Commands…}}).
2. Start typing what you want, for example *cloud*, *rotate* or *scale*.

   ![Searching for cloud in Find Tools + Commands](img/command-palette.png)
3. Use the arrow keys to pick a result and press [[Enter]], or click it.

The keyboard shortcut for each command is shown on the right, so you can learn it for next time.

> **Tip:** Greyed-out results are commands that cannot be used right now. For example, most commands need a document open first.

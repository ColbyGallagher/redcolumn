# Create form fields

Turn any PDF (an inspection sheet, a checklist, a transmittal) into a fillable form.

![Tools, Form](img/menu-form.png)

## Let redcolumn find the fields

1. Open the PDF.
2. Choose {{Tools > Form > Auto-Create Fields…}}.

redcolumn finds lines to write on, boxes to tick and areas for comments, and makes a field for each. A message says how many it made.

![Fields created automatically on an inspection form](img/auto-fields-result.png)

Check the result in the [Forms panel](#forms), and fix or delete any field that isn't right.

## Draw a field yourself

1. Open the **Forms** panel.
2. Choose the kind of field in the list at the top (for example Text or Check box).
3. Click **Draw field** (or choose {{Tools > Form > Draw Field}}).
4. Drag a box on the page where the field goes.

## Change a field's settings

Click the field in the Forms panel to show its settings:

![A field's settings in the Forms panel](img/draw-field-start.png)

| Setting | What it does |
|---|---|
| **Name** | The field's name (used when exporting data). |
| **Tooltip** | Help text shown when the pointer is over the field. |
| **Required / Read-only / Multi-line** | Must be filled in / can't be changed / allows several lines. |
| **Max length** | The most characters allowed. |
| **Appearance** | Text size, colours, border and when it shows (*Visible and printed*, *Visible, not printed*, *Hidden*, *Printed only*). |
| **Default** | The value **Reset** puts back. |
| **Validate** | Allow any value, a number in a range, or text matching a pattern. |
| **Calculate** | Work the value out from other fields (sum, average…). |
| **Format** | Show as a number, percent or date. |
| **When clicked** (buttons) | Go to a page, open a web page, reset the form, submit the data, or print. |

Use **↑ / ↓** beside each field to change the tab order. **Delete field** removes it.

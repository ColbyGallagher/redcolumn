# Single, continuous and side-by-side pages

You choose whether you see one page at a time or scroll through them all.

## Switch between Single and Continuous

Click the **Single / Continuous** button in the navigation bar.

![The Single / Continuous button](img/nav-continuous.png)

| Layout | What you see | What the mouse wheel does |
|---|---|---|
| **Single** | One page at a time. | Zooms in and out. |
| **Continuous** | All pages in one long column. | Scrolls up and down. Hold [[Ctrl]] to zoom. |

## All the layouts

Choose them from the {{View}} menu:

![The View menu page layouts](img/view-menu-layout.png)

| Command | Shortcut | Shows |
|---|---|---|
| **Single Page** | [[Ctrl+4]] | One page. |
| **Continuous Pages** | [[Ctrl+5]] | All pages in a column. |
| **Side-by-Side** | [[Ctrl+6]] | Two pages next to each other. |
| **Continuous Side-by-Side** | [[Ctrl+7]] | All pages, two to a row. |
| **Show Cover Page in Side-by-Side** | | Puts the first page on its own, like the cover of a book. |

![Two sheets side by side](img/layout-side-by-side.png)

> **Tip:** Side-by-side is good for checking a plan against its elevation. To compare two separate documents instead, use [Split the view](#split).

# Select markups

You must **select** a markup before you can move, change or delete it.

## Select one markup

1. Pick the **Select** tool: press [[V]] (or [[Esc]] until no tool is picked).
2. Click the markup. Handles (small squares) appear around it.

   ![A selected rectangle with its handles](img/select-handles.png)

To select nothing, press [[Esc]] or click an empty part of the page.

## Select several markups

| To | Do this |
|---|---|
| Add or remove one markup | Hold [[Shift]] and click it. |
| Select everything in an area | Hold [[Shift]] and drag a box on an empty part of the page. |
| Select every markup | Press [[Ctrl+A]] (Edit › Select All). |
| Select an odd-shaped area | Use the **Lasso** ([[Shift+O]]): drag a loop around the markups. |

![Two rectangles selected with Shift-click](img/select-shift.png)

![Dragging a selection box with Shift held](img/select-box.png)

These are all in the {{Edit}} menu:

![Select, Select All and Lasso in the Edit menu](img/edit-menu-select.png)

> **Tip:** Want a plain drag (without [[Shift]]) to draw a selection box? Turn on **Drag on the page to select markups** in [Preferences](#preferences) › **Markup**.

## Select from the list

Click a row in the [Markups list](#markups-list). The page jumps to that markup and selects it.

## Hard to click?

- Markups that are [locked](#group-lock) can be selected but not moved.
- A markup with a [link](#actions) follows its link when clicked. Hold [[Shift]] and click it to select it instead.

# Customise the toolbar

Put the tools you use most on the toolbar, and take off the ones you don't.

## Add or remove tools

1. Right-click any tool on the toolbar.
2. Point at **Toolbar Tools**, then **Markup** or **Measure**.

   ![The toolbar's right-click menu](img/toolbar-menu.png)
3. Click a tool to add it (a tick appears) or remove it (the tick goes).

## Remove one tool quickly

Right-click the tool and choose **Remove** *tool* **from Toolbar**.

## Put it back the way it was

Right-click the toolbar and choose **Reset Toolbar to Defaults**.

## Hide the whole toolbar

Choose {{Window > Tools Toolbar}}. Choose it again to show it.

> **Tip:** Different jobs need different tools. Save a toolbar layout for each with [Profiles](#profiles).

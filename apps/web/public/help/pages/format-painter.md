# Format Painter

Copies the **look** (colour, line, fill, font) of one markup onto other markups.

1. Select the markup whose look you want to copy.
2. Choose {{Edit > Format Painter}} (or press [[Ctrl+Shift+C]], or right-click › **Format Painter**).

   ![Format Painter in the Edit menu](img/edit-menu-painter.png)
3. Click each markup that should get the same look.
4. Press [[Esc]] when you are done.

Only the look is copied. The shape, text and comments of each markup stay the same.

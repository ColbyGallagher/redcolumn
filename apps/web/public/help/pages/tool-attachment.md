# File Attachment

Attaches a file (a spec sheet, photo, spreadsheet…) to a spot on the page. It shows as a paperclip icon, and the file is saved **inside** the PDF.

## Attach a file

1. Choose {{Tools > File Attachment}}, or press [[F]].

   ![Tools menu with File Attachment highlighted](img/menu-tools-other.png)
2. Pick the file and click **Open**. Files can be up to 25 MB.
3. Click on the page where the paperclip should go.

   ![A paperclip icon on the plan](img/draw-attachment.png)

## Open an attached file

Double-click the paperclip (with the Select tool). The file opens, or is saved to your computer.

> **Note:** Attached files make the PDF bigger by the size of the file.

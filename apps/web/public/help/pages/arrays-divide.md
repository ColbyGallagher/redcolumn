# Arrays and Divide

Make many copies round a centre or along a path, or mark a path at equal spacing, like AutoCAD's Array, Divide and Measure. Find them under {{Edit > Modify}}. For copies in rows and columns, use [Multiply](#multiply).

## Polar Array

![Six copies placed round a centre point](gif/polar-array.gif)

1. Select the markups and choose {{Edit > Modify > Polar Array}}.
2. In the bar, set the number of **Items** (the original included) and the **Fill** angle (360 for a full circle).
3. Click the centre.

Copies go round counter-clockwise. Untick **Rotate items** to keep them upright.

## Path Array

![Six copies spaced along a polyline](gif/path-array.gif)

1. Select the markups and choose {{Edit > Modify > Path Array}}.
2. Set the number of **Items**.
3. Click the line, polyline or outline to array along.

The items are spaced evenly from the path's start to its end. **Align to path** turns each one to follow the path.

## Divide / Measure

![Marking a polyline into five equal parts](gif/divide.gif)

Marks a line or outline with a Count markup, so you can count fixtures along a run.

1. Choose {{Edit > Modify > Divide / Measure}}.
2. Pick **Equal parts** and the number of parts (Divide), or **Every** and a spacing in the page's units (Measure).
3. Click the line or outline.

An open line is marked between its ends. A closed outline is marked from its first point all the way round.

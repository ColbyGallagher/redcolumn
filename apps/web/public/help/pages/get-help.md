# Get help and send feedback

Everything is in the {{Help}} menu:

![The Help menu](img/menu-help.png)

**Help**, **Technical Support** and **Make a Suggestion** also have buttons in the top bar, next to the search box, so you can reach them without opening the menu. On a narrow window the buttons are hidden; use the {{Help}} menu instead.

| Command | Does |
|---|---|
| **Find Tools + Commands…** | Search for any command. See [Find any tool](#find-tools). |
| **Help** ([[F1]]) | Opens this help. |
| **redcolumn Community** | Ask questions and share tips with other users (GitHub Discussions). |
| **Check for Updates** | Gets the newest version. |
| **Install App…** | See [Install the app](#install). |
| **Technical Support** | Report a problem (opens a GitHub issue). |
| **Make a Suggestion** | Ask for a new feature or a change. |
| **Send Log Files** | Saves a log file of recent activity, to attach to a problem report. |
| **Learn What's New** | What changed in this version. |
| **Keyboard Shortcuts Guide** | See [Keyboard shortcuts](#shortcuts). |

## Reporting a problem well

1. Choose {{Help > Send Log Files}}. A text file is saved to your computer.
2. Choose {{Help > Technical Support}}.
3. Say **what you did**, **what you expected**, and **what happened instead**. Attach the log file, and a screenshot if you can.

> **Note:** The log file holds the app's recent warnings and errors, and which browser you use. Open it and check it before you send it. Don't attach confidential drawings.

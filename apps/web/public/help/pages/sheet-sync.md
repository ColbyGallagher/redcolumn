# Keep the list in a spreadsheet

**Sync** writes the Markups list to a Google Sheet or an Excel workbook in OneDrive, and keeps it up to date as markups are added, changed or removed. Measurements go in as numbers, so the sheet can total them.

1. Click **Sync…** on the list's toolbar.

   ![The Sync Markups to a Spreadsheet window](img/sheet-sync.png)
2. Type a **Name** for the spreadsheet.
3. Click **Google Sheets** or **Excel in OneDrive**.
4. Sign in to your Google or Microsoft account when asked, and allow access.

The button changes to **Syncing ✓**. The sheet uses the list's visible columns, filter and sort.

Click **Syncing ✓** again to **Sync now** or **Stop syncing**.

> **Note:** Sync needs an internet connection, and the redcolumn site must be set up for Google or Microsoft sign-in. If a button says sign-in is *not set up for this site*, ask whoever runs your redcolumn site (see `docs/CLOUD-SETUP.md`).

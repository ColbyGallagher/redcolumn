# Combine PDFs

Join several PDFs into one.

1. Choose {{File > Combine…}} (also {{Batch > Combine PDFs…}}).

   ![The Combine window](img/combine.png)
2. Click **Add Files…** and pick the PDFs. The open document is already in the list.
3. Put them in order: select a file and click **↑** or **↓**. Click **Remove** to take one out.
4. Type the **File name** for the new PDF.
5. Click **Combine**.

The combined PDF opens in a new tab. The original files are not changed.

# Combine PDFs

Join several PDFs into one.

1. Choose {{File > Combine…}} (also {{Bulk > Combine PDFs…}}).

   ![The Combine window](img/combine.png)
2. Click **Add Files…** and pick the PDFs. The open document is already in the list.
3. Put them in order: drag a file up or down the list. The other files move aside as you drag, and the list scrolls when you reach its top or bottom edge. Press Esc while dragging to put the file back where it was. You can also select a file and click **↑** or **↓**. Click **Remove** to take one out. To drag, move or remove several files together, hold Ctrl (Cmd on a Mac) and click each one, or hold Shift and click to select a range. The list scrolls to follow the files you move.

   To read long file names, scroll the list sideways, or drag the bottom-right corner of the window to make it bigger.
4. Type the **File name** for the new PDF.
5. Click **Combine**.

The combined PDF opens in a new tab. The original files are not changed.

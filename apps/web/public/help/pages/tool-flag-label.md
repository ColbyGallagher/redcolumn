# Flag Label

A short label in a pennant (flag) shape. Use it for tags like RFI numbers, keynotes or item codes.

## Add a flag label

1. Choose {{Tools > Markup > Text & Notes > Flag Label}}.

   ![Tools menu with Flag Label highlighted](img/pick-flagLabel.png)
2. Drag a box for the label. The point of the flag is on the left.
3. Type the label, then press [[Ctrl+Enter]] or click away.

   ![A flag label reading RFI 012](img/draw-flag-label.png)

Change the fill colour and text size on the toolbar or in the [Properties panel](#properties).

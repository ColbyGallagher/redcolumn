# Work with several documents

Each open PDF gets its own **tab** above the drawing.

## Open another document in a new tab

1. Click the **+** at the end of the tabs.

   ![The + button to open a new tab](img/tabs-add.png)
2. Pick a PDF and click **Open**.

## Switch, move and close tabs

- **Switch:** click a tab.
- **Reorder:** drag a tab left or right.
- **Close:** click the **×** on the tab, middle-click the tab, or press [[Ctrl+F4]].
- **Close all:** press [[Ctrl+Shift+W]].

## The tab menu

Right-click a tab for more choices:

![The right-click menu on a tab](img/tab-menu.png)

| Choice | What it does |
|---|---|
| **Close All But This** | Closes every other tab. |
| **Close Tabs to the Right** | Closes the tabs after this one. |
| **Save / Save As…** | Saves this document. See [Save your work](#save). |
| **Save a Copy of the Original…** | Saves the PDF as it was before any markups. |
| **Add to Session** | Shares the document in a [Live Session](#sessions). |
| **Show in File Access** | Finds the file in the [File Access](#file-access) panel. |
| **Copy File Name** | Copies the name so you can paste it elsewhere. |
| **Open in Split View** | Shows this document beside another. See [Split the view](#split). |

# Text Highlight

Highlights words in the PDF, following the lines of text exactly. It only works on PDFs that contain real text (not scanned pictures of text — see [OCR](#ocr)).

## Highlight text

1. Choose {{Tools > Markup > Text Markup > Text Highlight}} (or press [[H]]).

   ![Tools menu with Text Highlight highlighted](img/pick-textHighlight.png)
2. Point at the first word. The pointer turns into a text cursor (I-beam) over text.
3. Drag across the words to highlight. You can drag over several lines.

   ![A note highlighted in yellow](img/draw-text-highlight.png)

The highlighted words are copied into the markup's **Comments**, so you can see them in the [Markups list](#markups-list).

> **Tip:** Nothing happens? The PDF may be a scan with no real text. Run [OCR](#ocr) first, or use the [Highlighter](#tool-highlighter) instead.

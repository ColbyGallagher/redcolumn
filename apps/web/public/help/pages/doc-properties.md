# Document properties

Shows facts about the PDF, and lets you change its title, author, subject and keywords.

1. Choose {{Document > Document Properties…}} (or press [[Ctrl+D]]).

   ![The Document Properties window](img/doc-properties.png)
2. Change the **Title**, **Author**, **Subject** or **Keywords** if you need to.
3. Click **Close**.

Below, you can see the file name, file size, number of pages, page sizes, PDF version, when it was created and modified, the program that made it, and its security.

> **Tip:** The title is what many PDF programs show in their title bar, so it is worth setting before you share a document.

# Markup basics (start here)

A **markup** is anything you add on top of the drawing: a cloud, an arrow, some text, a stamp. Markups never change the drawing underneath. You can move, change or delete them at any time.

Every markup tool works the same basic way. Learn it once here.

## 2. Draw it

Tools are drawn in one of four ways:

| How | Tools | What to do |
|---|---|---|
| **Drag** | Line, Arrow, Rectangle, Ellipse, Cloud, Text Box, Callout, Stamp… | Press the mouse button, drag, let go. |
| **Click points** | Polyline, Polygon, Polygon Cloud, Arc | Click each corner. Finish by pressing [[Enter]], double-clicking, or clicking the first point again. |
| **Freehand** | Pen, Highlighter | Hold the button down and draw. |
| **Click once** | Note, Flag, Typewriter, File Attachment | Click where it goes. |

Useful keys while drawing:

| Key | What it does |
|---|---|
| Hold [[Shift]] | Keeps lines straight: horizontal, vertical or at 45°. Makes squares and circles. |
| Hold [[Alt]] | Stops the point jumping (snapping) to nearby lines. |
| [[Backspace]] | Removes the last point you clicked (click-point tools). |
| [[Enter]] | Finishes a click-point shape. |
| [[Esc]] | Cancels what you are drawing. Press again to go back to the Select tool. |

## 3. Keep drawing, or stop

After you draw a markup, the tool stays picked so you can draw another. This is the **Reuse** switch in the status bar. To stop, press [[Esc]] or [[V]] to go back to the **Select** tool. See [Reuse a tool](#reuse).

## 4. Change it

1. Press [[V]] (the Select tool) and click the markup. Small squares (handles) appear around it.
2. Drag it to move it. Drag a handle to resize or reshape it.
3. Change its colour, line width and fill on the toolbar. See [Change colour, line and fill](#style).
4. Press [[Delete]] to delete it.

## 5. Find it again

Every markup is listed in the **Markups** list at the bottom of the screen, with who made it and when. See [The Markups list](#markups-list).

> **Note:** Markups are saved automatically on this device. To put them in the PDF file, [save](#save).

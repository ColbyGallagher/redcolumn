# Text Box

Adds a box of text to the drawing.

## Add a text box

1. Click **Text Box** on the toolbar, or press [[T]].

   ![The Text Box button on the toolbar](img/pick-text.png)
2. Drag a box where the text should go.
3. Type your text. Press [[Enter]] for a new line.

   ![Typing in a text box](img/draw-text-editing.png)
4. To finish, press [[Ctrl+Enter]] or click somewhere else on the page.

   ![The finished text box](img/draw-text.png)

> **Warning:** Pressing [[Esc]] while typing **cancels** what you typed. Use [[Ctrl+Enter]] or click away to keep it.

## Edit the text

Double-click the text box (with the Select tool) and type.

## Change the font, size and box

See [Format text](#text-formatting).

> **Tip:** Want text with no box, which grows as you type? Use [Typewriter](#tool-typewriter). Want an arrow pointing from the text? Use [Callout](#tool-callout).

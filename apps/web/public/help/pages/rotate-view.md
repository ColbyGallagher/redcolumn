# Rotate the view

Turn the page on screen, for example to read text that runs up the side of a sheet. This only changes **your view**. The PDF itself is not rotated.

## Rotate

- Choose {{View > Rotate View > Clockwise}} (or press [[Ctrl+Shift+Plus]]), or
- Choose {{View > Rotate View > Counterclockwise}} (or press [[Ctrl+Shift+-]]).

Each time turns the view a quarter turn (90°).

## Put it back

While the view is rotated, the status bar shows a **View 90°** (or 180°, 270°) button.

![A rotated view with the View 90° button in the status bar](img/rotate-view.png)

1. Click the **View 90°** button to turn the view back to normal.

> **Note:** To rotate the pages in the PDF itself, so they stay rotated when you save, see [Rotate pages](#page-rotate).

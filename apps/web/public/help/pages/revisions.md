# Revisions

redcolumn keeps earlier versions of a document on this device: the set as it was before each [Slip Sheet](#slip-sheet), before [Colour Processing](#colour), and before a restore.

1. Choose {{Document > Revisions…}}.

   ![The Revisions window](img/revisions.png)
2. For each earlier version you can:
   - **Open** it as its own document, for example to [compare](#compare) it with the current one.
   - **Restore** it — go back to that version. The current version is kept as a revision, so nothing is lost.
   - **Delete** it from this device.

You can also right-click a file in [File Access](#file-access) and choose **Revisions (*n*)…**.

> **Note:** Revisions are kept only on this device. They are not saved inside the PDF.

# Common questions

### Where are my files kept?

On **your** device, in the browser's storage. redcolumn has no server and no account. A PDF you open is copied into redcolumn's storage so it opens instantly and works offline; your original file is not changed until you [save](#save) to it.

### Are my markups saved if I close the browser?

Yes. Markups are kept automatically as you work. To get them **into the PDF file** (to send to someone, or open in another program), [save](#save).

### Why does Save download a file instead of saving over mine?

Some browsers (Firefox, Safari) don't let web apps write to files. In those, Save downloads a copy. Use Chrome or Edge, or [install the app](#install), to save straight to the file.

### Can I use redcolumn without internet?

Yes, once it has loaded once. [Install it](#install) to be sure. Live Sessions, Projects and spreadsheet sync need the internet.

### Can I open my Bluebeam markups?

Yes. Markups saved in a PDF from Bluebeam Revu open as normal. You can also import a `.bax` markup file, and import Revu tool sets (`.btx`) into the [Tool Library](#tool-sets). See [Exchange markups](#markup-exchange).

### My measurements are wrong.

The page's scale is wrong or not set. Check the **Scale** in the navigation bar. [Calibrate](#calibrate) from a known dimension, then measure that dimension to check.

### A tool I need isn't on the toolbar.

Most tools are only in the {{Tools}} menu at first. Right-click the toolbar to add them. See [Customise the toolbar](#toolbar). Or press [[Ctrl+Shift+K]] and type the tool's name.

### I can't select text or search a drawing.

It is probably a scan (a picture). Run [OCR](#ocr) first.

### My markup won't move.

It may be [locked](#group-lock), or the document may be read-only (for example a Live Session where you can only view). A banner over the drawing says why.

### How do I change the name on my markups?

Type it in **Author** at the bottom of the {{Edit}} menu, or in [Preferences](#preferences) › **General**.

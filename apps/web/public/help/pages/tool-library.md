# Use the Tool Library

The **Tool Library** keeps markups set up the way you like them (colour, line, subject, text), ready to use again with one click. For example: a red *Demolish* cloud, a blue *New work* cloud, a *Fire door* count.

## Open it

Click **Tool Library** on the panel rail.

![The Tool Library panel](img/tool-library.png)

It has **tool sets** (groups of tools):

| Set | Holds |
|---|---|
| **Recent Tools** | The tools you have drawn with lately, filled in automatically. |
| **My Tools** | Your own saved tools. Make as many sets as you like. |
| **Standard Tools** | Every tool in redcolumn, as a grid of buttons. |

Click the arrow beside a set's name to fold it up.

## Use a tool

- **Click** a tool, then draw on the page (or click to place a copy).
- **Drag** a tool from the panel onto the page to drop a copy there.

Press [[Esc]] when you have finished.

## Copy or style?

A tool saved from a markup can work two ways:

| Way | What clicking it does |
|---|---|
| **Place Copy** | Places an exact copy of the saved markup (same shape, size and text) where you click. |
| **Draw with Style** | Draws a **new** markup of the same type, using the saved look. |

Right-click a tool and choose **Place Copy** or **Draw with Style** to use the other way once. To change the normal way, see [Preferences](#preferences) › **Tools** › **Tool Library**:

![The Tool Library preferences](img/prefs-tool-library.png)

Tick **Keep the Tool Active after Placing** to place several copies in a row.

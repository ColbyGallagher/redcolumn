# Install the app and work offline

You can use redcolumn in a browser tab, or install it as an app. Installed, it:

- opens from its own icon, in its own window
- works with no internet connection
- can open PDFs straight from your file manager
- updates itself quietly in the background

## Install on a computer (Chrome or Edge)

1. Click **Install app** at the top right of the screen.

   ![The Install app button](img/install-button.png)
2. Click **Install**.

   ![The Install redcolumn window](img/install-dialog.png)

redcolumn now has its own icon on your desktop, Start menu or Dock.

## Install on a phone or tablet

- **iPhone / iPad (Safari):** tap the **Share** button, then **Add to Home Screen**, then **Add**.
- **Android (Chrome):** open the browser menu (**⋮**), tap **Install app**, then confirm.

Not sure? Click {{Help > Install App…}}. It shows the steps for your browser.

> **Note:** Firefox on a computer cannot install web apps. redcolumn still works offline in Firefox once it has loaded.

## Working offline

- Every PDF you open is kept on your device and works offline.
- When there is no network, the status bar shows **Offline**.
- Live Sessions, Projects and cloud storage wait until you are back online.
- OCR needs a one-time download before it works offline. See [Preferences](#preferences) › **Offline**.

## Updates

redcolumn checks for updates by itself and installs them when you are not in the middle of something. To check now, click {{Help > Check for Updates}}.

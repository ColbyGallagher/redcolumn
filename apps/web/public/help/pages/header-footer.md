# Headers, footers and page numbers

Add text such as the file name, date, page numbers or Bates numbers to the top or bottom of pages.

## Add headers and footers

1. Choose {{Document > Headers & Footers…}}.

   ![The Headers & Footers window](img/header-footer.png)
2. Type in any of the six boxes: **Header left / centre / right** and **Footer left / centre / right**.
3. To add something that fills itself in, click in a box and then click a button below:

   | Button | Inserts |
   |---|---|
   | **Page number** | `<<page>>` |
   | **Page count** | `<<pages>>` |
   | **Page label** | the sheet number |
   | **Bates number** | a running Bates number |
   | **File name** | `<<file>>` |
   | **Date** | today's date |

4. Choose the **Font**, **Size**, **Colour**, **Margin** and the **First page no.**
5. For Bates numbers, set the **Prefix**, **Start**, **Digits** and **Suffix**.
6. Choose the **Pages**, and click **Apply**.

## Number pages

Choose {{Document > Number Pages…}}. It is the same window, ready with *Page &lt;&lt;page&gt;&gt; of &lt;&lt;pages&gt;&gt;* in the footer.

![The Number Pages window](img/number-pages.png)

## Remove headers and footers

Open {{Document > Headers & Footers…}} again. When the document already has headers and footers added by redcolumn, the window has a **Remove existing** button. To remove them from many files, use {{Batch > Remove Headers & Footers…}}.

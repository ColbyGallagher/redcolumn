# Note

A small sticky-note icon on the page. The note's text stays hidden until someone opens it, so it does not clutter the drawing.

## Add a note

1. Choose {{Tools > Markup > Text & Notes > Note}}.

   ![Tools menu with Note highlighted](img/pick-note.png)
2. Click where the note goes.
3. Type your comment and click **OK** (or press [[Ctrl+Enter]]).

   ![Typing the note's comment](img/note-comment.png)

   ![The note icon on the plan](img/draw-note.png)

## Read or change a note

Double-click the note icon. The comment is also shown in the **Comments** column of the [Markups list](#markups-list).

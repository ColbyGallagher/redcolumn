# Glossary

| Word | Meaning |
|---|---|
| **Author** | The name recorded on each markup you make. Set it in the Edit menu or [Preferences](#preferences). |
| **Batch** | Doing one task to many files at once. See [Batch](#batch). |
| **BAX** | Bluebeam's markup file. See [Exchange markups](#markup-exchange). |
| **Calibrate** | Working out a page's scale from a length you know. See [Calibrate](#calibrate). |
| **Callout** | Text in a box with an arrow pointing at something. See [Callout](#tool-callout). |
| **Check out / check in** | Reserving a [Project](#projects) file while you work on it, then sending your changes back. |
| **Cloud** | A bumpy outline drawn around a change. See [Cloud](#tool-cloud). |
| **Compare** | Finding the differences between two revisions. See [Compare](#compare). |
| **Digital ID** | An electronic identity used to sign PDFs securely. See [Digital IDs](#digital-ids). |
| **Flatten** | Burning markups into the page so they can't be changed. See [Flatten](#flatten). |
| **Handle** | A small square on a selected markup that you drag to resize or reshape it. |
| **Layer** | A group of content you can show or hide. See [Layers](#layers). |
| **Link** | A clickable area that jumps to another sheet, view, file or web page. See [Sheet links](#links). |
| **Live Session** | Marking up the same documents with others at the same time. See [Live Sessions](#sessions). |
| **Markup** | Anything you add on top of the drawing: shapes, text, stamps, measurements. |
| **Match line** | A line where a drawing continues on another sheet. See [Stitched view](#stitch). |
| **OCR** | Reading the words in a scanned page so they can be searched. See [OCR](#ocr). |
| **Overlay** | Two revisions stacked in colour on one page. See [Overlay](#overlay). |
| **Page label** | A page's sheet number, such as A-101. See [Page labels](#page-labels). |
| **Pan** | Moving the page around without zooming. See [Move around](#move-around). |
| **Panel rail** | The column of buttons at the left that opens the side panels. |
| **Place** | A named, saved view that links can jump to. See [Bookmarks](#bookmarks). |
| **Profile** | A saved workspace layout: toolbar, panels, tools, list columns, shortcuts. See [Profiles](#profiles). |
| **Redaction** | Permanently removing private content from a PDF. See [Redaction](#tool-redaction). |
| **Revision** | An earlier version of a document, kept on this device. See [Revisions](#revisions). |
| **Scale** | How real-world lengths relate to lengths on the paper, for example 1/4" = 1'-0". See [Set the scale](#scale). |
| **Set** | Several drawing files shown as one list of sheets. See [Sets](#sets). |
| **Slip sheet** | Putting new revisions of sheets in place of old ones, keeping markups. See [Slip sheet](#slip-sheet). |
| **Snap** | The pointer jumping to an exact corner, end or crossing. See [Snapping](#snapping). |
| **Space** | A named room or zone that groups the markups inside it. See [Spaces](#spaces). |
| **Status** | Where a markup is in a review, such as Accepted. See [Statuses](#list-status). |
| **Subject** | A markup's name in the list and in legends, such as *Demolish*. |
| **Takeoff** | Measuring quantities (lengths, areas, counts) from drawings. |
| **Tool Library** | Saved markup tools, ready to reuse. See [Tool Library](#tool-library). |
| **Viewport** | An area of a page with its own scale. See [Viewports](#viewports). |
| **XFDF** | The standard file for exchanging PDF markups. See [Exchange markups](#markup-exchange). |

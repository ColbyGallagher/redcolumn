# File Access (your files on this device)

The **File Access** panel lists every PDF you have opened on this device. They open instantly and work offline.

![The File Access panel](img/file-access.png)

1. **Filter files** — type part of a name to find a file quickly.
2. **+ Group** — make a group (like a favourites folder) for files you use together.
3. **Recents** — every PDF you have opened, newest first. Click one to open it.

## Open the panel

Click **File Access** on the panel rail.

## Make a group of files

1. Click **+ Group**.
2. Type a name (for example *Level 2 drawings*) and press [[Enter]].
3. Drag files from **Recents** onto the group. Or right-click a file and choose **Add to Group**.

To open every file in a group at once, right-click the group and choose **Open All**.

## Remove a file from this device

1. Right-click the file (or click its **⋯** button).
2. Choose **Remove from Device…** and click **OK**.

> **Note:** Removing a file only removes redcolumn's copy. The PDF on your computer is not touched. If you open the same PDF again later, your markups come back.

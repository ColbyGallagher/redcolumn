# Save your own tools

## Save a markup as a tool

1. Draw a markup and set it up how you want it: colour, line width, fill, and a **Subject** in the [Properties panel](#properties) (for example *Demolish*).
2. Right-click it and point at **Add to Tool Library**.
3. Click the tool set to put it in (for example **My Tools**), or **New Tool Set…**.

   ![Add to Tool Library on the right-click menu](img/add-to-tool-library.png)

The tool appears in the Tool Library, named after its subject.

![The saved Demolish tool in My Tools](img/tool-library-saved.png)

> **Tip:** You can also drag a tool from **Recent Tools** into another set, or select a markup and use the set's **⋯** menu › **Add Selected Markup**.

## Change a saved tool

Right-click the tool in the panel:

![The menu for a saved tool](img/tool-menu.png)

| Choice | Does |
|---|---|
| **Place Copy / Draw with Style** | Uses the tool the chosen way, once. |
| **Rename…** | Changes the tool's name. |
| **Move to Tool Set** | Moves it to another set. |
| **Duplicate** | Makes a copy to change. |
| **Delete Tool** | Removes it from the library. |

To change how a tool looks, place a copy, restyle it, and save it again.

> **Tip:** Some imported tools are *numbered* (for example keynote bubbles): each copy you place gets the next number.

# Symbol Search

Finds every copy of a symbol (a light fitting, a socket, a tree) on the page or in the whole document, then counts or marks them all.

1. Zoom in so you can see one copy of the symbol clearly.
2. Choose {{Tools > Measure > Symbol Search}}.

   ![Tools, Measure, Symbol Search](img/pick-visualSearch.png)
3. Drag a tight box around **one** copy of the symbol.
4. The **Symbol Search** panel opens and shows how many were found.

   ![The Symbol Search panel](img/symbol-search-panel.png)

   | Option | Use it to |
   |---|---|
   | **All *n* pages** | search every page, not just this one |
   | **Include rotated copies** | also find copies turned at an angle |
   | **Include larger and smaller copies** | also find copies drawn at another size |
   | **Match the image (scanned sheets)** | search scanned drawings by their pixels |

5. Click **‹ Prev** and **Next ›** to check each one.
6. Under **Mark all as**, click what to make:
   - **Count** — one [count](#measure-count) per page, with a dot on each copy.
   - **Clouds** or **Boxes** — a cloud or box around each copy.
   - **Hyperlinks…** — a link on each copy, all going to the same place.

![Every light fitting counted](img/symbol-search-counted.png)

> **Tip:** Found too many? Untick the options, or draw a tighter box.

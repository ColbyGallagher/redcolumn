# Go to another page

## Use the navigation bar

The page controls are in the middle of the navigation bar, under the drawing.

![Page controls in the navigation bar](img/nav-pages.png)

1. **Previous view** — go back to where you were looking before.
2. **First page**.
3. **Previous page**.
4. **Page number** — click it, type a page number and press [[Enter]].
5. **Next page**.
6. **Last page**.
7. **Next view** — go forward again after going back.

To the right you can see the **sheet number and title** (for example *A-101 GROUND FLOOR PLAN*), the **page size** and the page's **Scale**.

## Use the keyboard

| Key | Goes to |
|---|---|
| [[Page Down]] | Next page |
| [[Page Up]] | Previous page |
| [[Home]] | First page |
| [[End]] | Last page |

## Use the thumbnails

1. Click **Thumbnails** on the panel rail.
2. Click the picture of the page you want.

   ![The Thumbnails panel](img/thumbs-go.png)

## Right-click the page

Right-click an empty part of the page for quick page commands: next and previous page, zoom, page layout, rotate, insert, extract and delete pages.

![The page right-click menu](img/page-menu.png)

## Follow a sheet link

References to other sheets on a drawing (for example *SEE A-201*) are found automatically and outlined in blue. Click one to jump to that sheet. See [Sheet links](#links).

> **Tip:** Press [[Alt+Left]] to come back after following a link.

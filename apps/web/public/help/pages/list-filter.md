# Search, filter and sort

## Search

Type in **Search markups**. The list shows only markups with that text anywhere in them: subject, comment, text, replies, status, author or any column.

![Searching the list for "floor"](img/list-search.png)

Press [[Esc]] in the box to clear it.

## Filter by column

1. Click **Filter** on the list's toolbar. A row of filter boxes appears under the column names.
2. Type in a column's box, or pick from its list.

   ![Filtering the Subject column](img/list-filter-row.png)

You can type special filters in a box:

| Type | Finds |
|---|---|
| `text` | cells containing the text |
| `!text` | cells **not** containing it |
| `=text` | cells that are exactly the text |
| `>10`, `<=5` | numbers bigger or smaller |
| `(blank)` | empty cells |

Click **Clear** to remove every filter.

## Save a filter to use again

1. Set up the filter.
2. Click **Save filter** and type a name.

Pick it later from the **All markups** list. Saved filters are kept in your [profile](#profiles).

## Filter Builder (several conditions)

1. Click **Filter Builder…**.
2. Choose whether markups must match **all** or **any** of the conditions.
3. For each condition, pick a column, a test (*contains*, *is*, *is greater than*, *is empty*…) and a value. Click **+ Add condition** for more.

   ![The Filter Builder](img/filter-builder.png)
4. Click **Apply**.

## What happens on the page

**On page** decides how markups the filter leaves out look on the drawing: **Show all**, **Dim filtered out**, or **Hide filtered out**.

## Sort

Click a column heading to sort by it. Click again to reverse. Right-click a heading for **Sort Ascending**, **Sort Descending** and **Clear Sort**.

![The column heading menu](img/list-header-menu.png)

## Arrange the columns

- **Reorder:** drag a column heading left or right.
- **Resize:** drag the edge of a heading.
- **Hide:** right-click a heading › **Hide**.

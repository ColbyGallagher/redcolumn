# Hyperlink

Makes an area of the page clickable. Clicking it can jump to another page, a saved view, another PDF, or a web page.

## Make a link

1. Choose {{Tools > Hyperlink}}, or press [[Shift+H]].
2. Drag a box over the area that should be clickable (for example a detail reference).
3. Choose what clicking it does:

   ![The Action window](img/hyperlink-dialog.png)

   | Choice | Clicking the link… |
   |---|---|
   | **Jump to page** | goes to a page in this document. Tick **Zoom to an area** and click **Choose area…** to zoom to a part of that page. |
   | **Jump to Place** | goes to a saved view. Places are made in the [Bookmarks panel](#bookmarks). |
   | **Open document** | opens another PDF from [File Access](#file-access), at the page you type. |
   | **Open web page** | opens a web address. |

4. Click **OK**.

## Use a link

Click it with the Select tool. To select a link (to move or change it) instead of following it, hold [[Shift]] and click it, or drag it.

## Change where it goes

Double-click the link and change the action.

> **Tip:** Any markup can have a link, not just this tool. Select it and choose {{Edit > Edit Action…}}. See [Actions](#actions).

> **Note:** Sheet references are linked automatically. See [Sheet links](#links).

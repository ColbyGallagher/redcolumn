# Page setup (page size)

Change the paper size of pages, for example to make a mixed set all ARCH D, or to turn an A1 sheet into A3.

1. Choose {{Document > Page Setup…}}.

   ![The Page Setup window](img/page-setup.png)
2. Choose the **Pages**.
3. Under **New page size**, pick the size and **Portrait** or **Landscape**.
4. Leave **Scale content to fit** ticked to shrink or grow the drawing to fill the new size. Untick it to keep the drawing the same size, centred on the new page.
5. Click **OK**.

Markups move and scale with the content.

> **Note:** Scaling a drawing changes its printed scale. If you scale content, [set the scale](#scale) again (or calibrate) before measuring.

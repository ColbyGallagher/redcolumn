# Callout

Text in a box with an arrow (leader) pointing at something.

## Add a callout

1. Click **Callout** on the toolbar, or press [[Q]].

   ![The Callout button on the toolbar](img/pick-callout.png)
2. Press on the thing you want to point at. This is where the **arrow tip** goes.
3. Drag to where you want the **text**, and let go.
4. Type your text, then press [[Ctrl+Enter]] or click away.

   ![A callout pointing at a window](img/draw-callout.png)

## Move it

With the Select tool:

- Drag the **text box** to move only the text. The arrow keeps pointing at the same spot.
- Drag the **arrow tip** handle to point somewhere else.

## Edit the text

Double-click the callout and type.

See [Format text](#text-formatting) to change the font, size and box.

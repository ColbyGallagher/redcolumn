# Publish a clean copy

**Publish** saves a copy to hand out: markups burned in so they can't be changed, and the file cleaned up. The document you are working on is not changed.

1. Choose {{File > Publish…}}.

   ![The Publish window](img/publish-dialog.png)
2. Choose the options:
   - **Flatten markups** — markups become part of the drawing and can't be edited or removed.
   - **Remove editing history** — writes the file again from scratch, so earlier versions hidden inside the PDF are gone.
   - **Compress pictures** — makes the file smaller.
3. Click **Publish** and choose where to save the copy.

> **Tip:** Publish before you send drawings outside your team. People see exactly what you marked up, in any PDF reader.

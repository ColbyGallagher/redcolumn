# Count

Counts items: light fittings, outlets, doors, trees. Each click adds one.

1. Choose {{Tools > Measure > Count}} (or press [[Alt+Shift+C]]).

   ![Tools, Measure, Count](img/pick-count.png)
2. Click on each item. A dot marks each one and the running total is shown.
3. Press [[Enter]] when you have counted them all.

   ![Eight light fittings counted](img/measure-count.png)

All the dots from one go are **one** count markup, so the list shows one row with the total (for example *8 ea*).

> **Tip:** Counting the same symbol across a big set? [Symbol Search](#symbol-search) finds them all for you.

> **Tip:** Clicked one by mistake? Press [[Backspace]] before you press Enter.

# Count

Counts items: light fittings, outlets, doors, trees. Each click adds one.

1. Choose {{Tools > Measure > Count}} (or press [[Alt+Shift+C]]).

   ![Tools, Measure, Count](img/pick-count.png)
2. Click on each item. A dot marks each one and the running total is shown.
3. Press [[Enter]] when you have counted them all.

   ![Eight light fittings counted](img/measure-count.png)

All the markers from one go are **one** count markup, so the list shows one row with the total (for example *8 ea*).

## Marker shape & custom symbols

- Pick a **Marker shape** (Circle, Square, Triangle, Diamond, Cross, or Checkmark) in the **Properties** panel or the **Format** tab, either before counting or with an existing count selected.
- Choose **Manage symbols…** in the shape picker to save your own reusable symbols — create a vector badge (such as `D1` or `SD` in a circle or square), import a PNG/JPEG picture, or convert a stamp or Tool Library item.
- You can also select any drawn markup or group on the page, right-click, and choose **Save as Count Symbol…**.
- Right-click a styled count and choose **Add to Tool Library** to save its shape, symbol, colour, and size into a tool set.

> **Tip:** Counting the same symbol across a big set? [Symbol Search](#symbol-search) finds them all for you.

> **Tip:** Clicked one by mistake? Press [[Backspace]] before you press Enter.

# The Properties panel

The Properties panel shows **everything** about the selected markup, and lets you change it.

## Open it

- Click **Properties** on the panel rail, **or**
- Right-click a markup and choose **Properties**.

![The Properties panel for a selected cloud](img/properties-panel.png)

## What is in it

| Section | What you can change |
|---|---|
| **General** | **Subject** (the markup's name in the list), **Status**, **Checked**, **Comment**. Also shows its type, page, author and when it was changed. |
| **Appearance** | Colour, line width, line style, opacity, fill, hatch, cloud arcs and more. |
| **Text** (text markups) | Font, size, bold/italic/underline, alignment, text colour. |
| **Line endings** (lines, arrows, callouts) | The arrowhead at the **Start** and **End**, and its size. |
| **Measurement** (measurements) | Scale, units, depth, slope and how the value is shown. |
| **Custom Columns** | Your own columns. See [Columns](#list-columns). |

Changes apply straight away. With several markups selected, a change applies to all of them.

## With nothing selected

The panel shows the **tool defaults**: the look the current tool will use for new markups.

## Buttons at the bottom

- **Set as default** — new markups of this type will look like this one.
- **Reset style** — puts the markup back to the standard look.

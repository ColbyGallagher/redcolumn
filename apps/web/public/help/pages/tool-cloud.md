# Cloud

Draws a revision cloud: a box with a bumpy, cloud-like edge. Clouds are the usual way to show what has changed or what needs attention.

## Draw a cloud

1. Click **Cloud** on the toolbar, or press [[C]].

   ![The Cloud button on the toolbar](img/pick-cloud.png)
2. Press at one corner of the area, drag to the opposite corner, and let go.

   ![A cloud around the kitchen](img/draw-cloud.png)

## Change the size of the bumps

With the Cloud tool picked (or a cloud selected), choose a size in **Bubbles** on the toolbar. **Auto** picks a size that suits your zoom.

## Add a note to it

- Use [Cloud+](#tool-cloud-plus) to draw a cloud and a note in one go, or
- Right-click the cloud and add a comment. See [Comments](#comments).

> **Tip:** For a cloud that follows an odd shape, use [Polygon Cloud](#tool-polygon-cloud).

# Archive as PDF/A

**PDF/A** is the standard for keeping documents long-term: everything needed to show the file (fonts, colours) is stored inside it.

1. Choose {{Document > Archive as PDF/A…}}.
2. redcolumn makes a PDF/A-2b copy and saves it as *name (PDF-A).pdf*.

If something in the document can't be made PDF/A, redcolumn lists the problem and asks whether to save an archive copy anyway (not marked as PDF/A).

> **Note:** The first time, redcolumn downloads the fonts it embeds (about 4 MB).

# Actions (what a click does)

Any markup can be given an **action**: clicking it jumps to a page, a saved view, another document or a web page. For example, make a cloud jump to the detail sheet it refers to.

## Give a markup an action

1. Select **one** markup.
2. Choose {{Edit > Edit Action…}} (or press [[Ctrl+Shift+E]], or right-click › **Edit Action…**).
3. Choose where it goes:

   ![The Action window](img/hyperlink-dialog.png)

   - **Jump to page** — optionally tick **Zoom to an area** and click **Choose area…**.
   - **Jump to Place** — a saved view from the [Bookmarks panel](#bookmarks).
   - **Open document** — another PDF on this device, at a page.
   - **Open web page** — type the address.
4. Click **OK**.

## Use it

Click the markup with the Select tool. To select it instead of following the action, hold [[Shift]] and click.

## Remove an action

Open {{Edit > Edit Action…}} again and click **Remove Action**.

See also the [Hyperlink](#tool-hyperlink) tool, which draws a clickable area with no visible markup.

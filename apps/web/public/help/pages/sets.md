# Sets (drawing sets)

A **Set** shows the sheets of several PDF files as one list, sorted by sheet number. Click a sheet and it opens, whichever file it is in. Great for a project issued as one file per discipline.

## Make a set

1. Open the drawing files at least once, so they are in [File Access](#file-access).
2. Click **Sets** on the panel rail.
3. Click **New Set…**.
4. Type a **Set name**, and tick the files that belong in it.

   ![Making a new set](img/sets-new.png)
5. Click **Create**.

redcolumn reads every file's sheet numbers and lists all the sheets together.

![A set listing sheets from two files](img/sets-panel.png)

## Use a set

- **Click a sheet** to open it at that page.
- **‹** and **›** beside the set's name step to the previous and next sheet in the whole set, across files.
- **Filter sheets** at the top finds sheets by number or title.

## Change a set

Click the **⚙** (Files and categories) button beside the set's name:

![Editing a set's files and categories](img/sets-files.png)

- **Order** — sort sheets **By sheet number** or **In file order**.
- **Category** — type a heading for each file (for example *Architectural*, *Civil*). Sheets are grouped under it.
- **↑ / ↓** — move a file up or down; **×** removes it from the set.
- **Add a file…** — add another file.
- **Re-read sheets** — read the sheet numbers again after a file has changed.
- **Delete set** — removes the set (the files are kept).

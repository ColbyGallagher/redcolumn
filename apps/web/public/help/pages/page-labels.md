# Page labels (sheet numbers)

A **page label** is the sheet number of a page, such as *A-101*. redcolumn shows it under each thumbnail, in the navigation bar, and in the Markups list's **Page Label** column. It also uses labels to [link sheets](#links) and match revisions.

When you open a drawing set, redcolumn finds the sheet numbers by itself from the title blocks. If it gets one wrong, or a set has none, set them yourself.

## Change one page's label

1. In the [Thumbnails panel](#thumbnails), click the page.
2. Type the sheet number in **Label** and press [[Enter]].

## Read labels from the title block of every page

1. Go to a page and choose {{Document > Page Labels > From Page Region…}}.

   ![Document, Page Labels](img/menu-document-labels.png)
2. Drag a box around the **sheet number** in the title block. Draw a second box around the sheet title if you want both.

   ![The Page Labels from Regions panel](img/label-regions.png)
3. Check the preview (*Page 1: A-101*).
4. Choose **Set as**: **Page label** or **Sheet title**, and the **Pages**.
5. Click **Apply to *n* pages**.

Each page gets the text found in the same place on that page.

> **Tip:** Doing this to many files? Use [Batch Page Labels](#batch-page-labels).

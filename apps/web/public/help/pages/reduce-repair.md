# Reduce file size and repair

## Reduce file size

Makes the PDF smaller, to email it or save space.

1. Choose {{Document > Reduce File Size…}}.

   ![The Reduce File Size window](img/reduce-size.png)
2. Leave **Recompress JPEG pictures** ticked to shrink photos too. Lower the quality number (0 to 1) for a smaller file; `0.7` is a good balance.
3. Click **OK**.

Old revisions, deleted pages, unused fonts and pictures are dropped, and the rest is packed more tightly.

## Repair PDF

If a PDF opens slowly, shows errors, or other programs complain about it, choose {{Document > Repair PDF}}. redcolumn reads it and writes a clean copy.

> **Note:** Reducing or repairing a digitally **signed** PDF breaks the signature. redcolumn asks before it does this.

To do this to many files, use {{Batch > Reduce File Size…}} or {{Batch > Repair…}}.

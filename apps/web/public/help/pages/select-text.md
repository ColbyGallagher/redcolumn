# Select and copy PDF text

Copy words from the drawing (for example a note or a schedule) to paste into an email or spreadsheet.

## Quick way

With the **Select** tool, press on a word in the drawing and drag across the text. The text is copied as soon as you let go: a message says how many characters were copied. Paste it anywhere with [[Ctrl+V]].

## The Select Text tool

1. Choose {{Edit > PDF Content > Select Text}} (or press [[Shift+T]]).

   ![Edit, PDF Content](img/menu-pdf-content.png)
2. Drag across the text. You can drag over several lines.

   ![Text selected and copied](img/select-text.png)

Press [[V]] to go back to the Select tool.

> **Note:** Scanned drawings have no text until you run [OCR](#ocr).

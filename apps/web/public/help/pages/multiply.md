# Multiply (make many copies)

Makes a grid of evenly spaced copies. Use it for rows of parking spaces, light fittings, desks and so on.

1. Select the markup (or markups) to copy.
2. Choose {{Edit > Multiply…}} (or press [[Ctrl+M]], or right-click › **Multiply…**).
3. Fill in the grid:

   ![The Multiply window](img/multiply-dialog.png)

   | Box | Means |
   |---|---|
   | **Columns** | How many copies across. |
   | **Horizontal spacing** | The gap between copies across. |
   | **Rows** | How many copies down. |
   | **Vertical spacing** | The gap between rows. |

   The original is the top-left copy. Spacing is in the page's [scale](#scale) units (for example feet), or inches on the paper when no scale is set.
4. Click **Make *n* copies**.

![A grid of copies](img/multiply-result.png)

> **Tip:** Press [[Ctrl+Z]] to undo all the copies at once.

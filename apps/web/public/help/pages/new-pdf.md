# Create a new PDF

## A blank PDF

1. Choose {{File > New PDF…}}.

   ![The New PDF window](img/new-pdf.png)
2. Choose the **Page size** (Letter, A4, ARCH D…), **Portrait** or **Landscape**, and how many **Pages**.
3. Click **Create**.

The new PDF opens in a tab. Mark it up like any other document, and [save](#save) it.

## From a template

Use any PDF you use often (a site report, a transmittal, a title block) as a template.

1. **Mark it as a template once:** in [File Access](#file-access), right-click the PDF and choose **Use as Template**.
2. **Make a new document from it:** choose {{File > New PDF from Template…}}, pick the template, type a name, and click **Create**.

The new document is a copy. The template itself is not changed.

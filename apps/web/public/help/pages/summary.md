# Markup Summary report

A report of every markup: a table you can print, file or send, with comments, statuses and measurements.

1. Choose {{File > Export > Markup Summary…}} (or click **Export…** on the [Markups list](#markups-list)).

   ![The Export Markup Summary window](img/summary-dialog.png)
2. Choose **PDF** (a formatted report) or **CSV** (for Excel).
3. For a PDF, choose the **Layout**: **Comments only** (just the table) or **Original + summary** (the marked-up drawing with the table at the end).
4. Type a **Title**.
5. Choose the **Markups**: only those the list shows (after filtering), or all of them.
6. Tick the **Columns** to include.
7. Click **Export PDF** (or **Export CSV**).

> **Tip:** Filter the list first (for example status *Open*, or one trade) to make a focused report. See [Search, filter and sort](#list-filter).

For many files at once, use [Batch Summary](#batch-summary-print).

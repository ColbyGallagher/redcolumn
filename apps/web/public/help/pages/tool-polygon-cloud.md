# Polygon Cloud

Draws a revision cloud along any outline, corner by corner. Use it when a plain rectangle cloud does not fit the area.

## Draw a polygon cloud

1. Choose {{Tools > Markup > Lines & Shapes > Polygon Cloud}}.

   ![Tools menu with Polygon Cloud highlighted](img/pick-polygonCloud.png)
2. Click each corner of the area.
3. Finish by clicking the **first** corner again, double-clicking, or pressing [[Enter]].

   ![An L-shaped polygon cloud](img/draw-polygon-cloud.png)

Change the bump size with **Bubbles** on the toolbar, as for a [Cloud](#tool-cloud).

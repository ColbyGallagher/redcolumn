# Projects

A **Project** is a shared folder of PDFs in OneDrive. Everyone on the Project opens the files from redcolumn, checks them out to work on them, and checks them back in. Every check-in keeps a revision, and a **Project Record** logs who did what.

> **Note:** Projects are **experimental**, and need a Microsoft account (personal, work or school) and a site set up for OneDrive.

![The Projects panel](img/projects-panel.png)

## Make a Project

1. Click **Projects** on the panel rail.
2. Click **+ New**, type a **Project name**, and click **Create**. Sign in to Microsoft if asked.
3. Click **Add PDFs…** to add files, or **Add open document**. Make folders to organise them.

## Invite people

1. Click **Manage project…**.
2. Under **Sharing**, add each person's Microsoft account email and choose **Can view** (open and read) or **Can edit** (open, check out and in, add and change files).
3. Send them the link: click **Copy invite link**.

## Open a Project someone shared

Click their invite link, then **Open Project**. Or click **Open…** in the Projects panel and paste the Project link (or its OneDrive folder link).

## Work on a file

Click a file to see what you can do:

| Button | Does |
|---|---|
| **Open** | Opens the file to read. |
| **Check Out** | Reserves the file for you, so nobody else changes it meanwhile. |
| **Check In…** | Sends your changes back, with a comment. A revision is kept. |
| **Undo Check Out** | Gives the file back without your changes. |
| **Release Check Out** | (Owner) frees a file someone else has checked out. |
| **Add Note…** | Adds a note about the file to the Project Record. |
| **Rename… / Delete** | Renames or deletes the file. |

Under revisions, **Open** an earlier version, or **Restore** it.

The panel also shows who else has the file open now, and on which page.

## Working offline

If OneDrive can't be reached, check-ins are queued. Click **Send now** when you are back online (or **Retry** / **Discard** for one that failed).

## Project Record

**Project Record** lists every check-out, check-in, note and change, with who and when.

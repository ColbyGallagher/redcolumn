# Bulk Summary and Print

## One markup report for many files

1. Choose {{Bulk > Markup Summary…}}.

   ![The Bulk Markup Summary window](img/batch-summary.png)
2. Choose the **Format**: **CSV (spreadsheet)**, **XML**, or **PDF summary**.
3. Tick the files and click **Run on *n* files**.

You get one report listing every markup in all the files, with the file each one is in.

## Print many files

1. Choose {{Bulk > Print…}}.

   ![The Bulk Print window](img/batch-print.png)
2. Choose what to **Print**: **Document and markups**, **Document only**, or **Markups only**.
3. Tick the files. They print in the order listed.
4. Click **Run on *n* files**. One print window opens for all of them.

See also [Print](#print).
